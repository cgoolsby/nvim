# nvim

Neovim configuration.

## Setup

Bootstrapped automatically by [cgoolsby/initialize](https://github.com/cgoolsby/initialize) — cloned to `~/nvim` as part of `setup.sh`.

To set up manually:

```bash
git clone git@github.com:cgoolsby/nvim.git ~/nvim
```

Neovim will pick up the config from `~/nvim` when `$XDG_CONFIG_HOME` or `~/.config/nvim` points there, or when Neovim is launched from that directory depending on your setup.
